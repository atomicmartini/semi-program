# 기능: 사용자가 뉴스 카드 아래에서 이어지는 흐름을 펼쳐 볼 수 있다

`WBS.md` 7.1 의 화면 절반. 데이터는 `link.py`(슬라이스 01)가 이미 만든 `<날짜>.linked.json` 을 쓴다.
화면 구조는 `docs/ui/d-merged.html` 의 `.thread`/`.rail`/`.step` 을 그대로 가져온다 — 새로 디자인하지 않는다.

## 완료 조건

- [ ] `related` 가 있는 카드에 "이어지는 흐름 N건" 이 펼쳐진 상태로 보이고, 과거 기사 날짜·제목이 **오래된 것부터** 나온다
- [ ] `related` 가 없는 카드는 그 영역 자체가 안 보인다 (빈 칸을 만들지 않는다)
- [ ] 과거 기사 제목을 누르면 그 기사 원문으로 이동한다

## 안 되는 경우

- 그날 `<날짜>.linked.json` 파일이 아예 없을 때 (아직 `link.py` 를 안 돌린 날) → 에러 없이 그냥 흐름 영역을 생략한다

## 이번에 안 하는 것

- **"확정"/"보도됨" 배지는 안 넣는다** — 그건 `extract.py` 의 관계·인용구 검증이 있어야 근거가 있다. 지금은 공통 기업 언급뿐이라 배지를 달면 있는 근거보다 과한 주장이 된다
- **"달라진 점" 문장은 안 넣는다** — `PLAN.md` 에서 이미 범위 밖으로 정함
- `render.py --all` 이 지금 도는 14일 중 `link.py` 를 미리 돌려둔 날만 흐름이 보인다. 매일 자동으로 같이 도는 것은 `8.1 daily.yml` 몫

## 건드릴 파일

- 고칠 파일: `render.py` (STYLE 에 rail 스타일 추가, CARD 에 흐름 블록 추가, `render_news` 에서 linked.json 읽어 붙이기)
- 새로 만들 파일: `test_render.py` (흐름 블록을 오래된 순으로 정렬하는 로직만 테스트)
