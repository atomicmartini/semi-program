# 기능: 사용자가 영어 기사도 한국어 요약으로 읽을 수 있다

`ROADMAP.md` 4번. **A안으로 정해졌다 — 카드의 요약만 한국어로 바꾼다.**
기사마다 번역 전문 페이지를 따로 만들지 않는다 (`PRD.md` 저작권 제약).

## 지금 무엇이 문제인가

영어 기사 **170건**의 '요약'은 RSS 가 준 **본문 첫 문장을 자른 것**이다.

> 제목: *First 2D Semiconductor FPGA Achieves Wafer-Scale Integration*
> 요약: *The global IC industry is confronting the physical limitations of Moore's Law.*

무슨 일이 있었는지가 없다. `extract.py` 는 `summary_ko` 를 만들어 놓았는데
**화면이 그 파일을 안 읽는다.**

## 완료 조건

- [ ] 배포된 URL 의 영어 기사 카드에 **한국어 요약**이 보인다
- [ ] `summary_ko` 가 없는 기사는 원래 요약이 그대로 보인다 (빈칸이 되지 않는다)
- [ ] 모델이 만든 요약임을 카드에 밝힌다 — 기자가 쓴 문장인 것처럼 보이지 않게 한다

## 안 되는 경우

- 그날 `.extracted.json` 이 없음 → 원래 요약 그대로. 에러 아님
- 그 기사만 `extract_error` 가 있음 → 원래 요약 그대로
- `summary_ko` 가 빈 문자열 → 원래 요약 그대로 (빈 카드를 만들지 않는다)

## 이번에 안 하는 것

- **제목은 안 바꾼다** — 영어 제목 그대로. 원문을 찾아갈 때 필요하다
- **번역 전문 페이지 안 만든다** (B안, `PRD.md` 저작권)
- **관계(`relations`)는 화면에 안 쓴다** — 흐름은 아직 `link.py` 의 기업 겹침으로만 잇는다
- 연결고리 기준 높이기(`ROADMAP` 1번)는 다음 작업

## 함께 고치는 것 두 가지

`ROADMAP.md` 가 이 슬라이스에 넣기로 한 것들이다.

| 무엇 | 왜 |
| --- | --- |
| **모델이 `미분류` 를 주면 키워드 분류를 그대로 둔다** | `super-120b` 가 영어 기사를 `미분류` 로 틀렸는데 `filter.py` 는 키워드로 맞혔다. 지금은 모델 답이 그걸 덮어쓴다. **판정은 코드가 한다**(`CLAUDE.md`) |
| **이미 뽑은 기사는 모델을 다시 안 부른다** | 125일치를 돌리려면 수백 번 호출한다. 중간에 끊기면 처음부터 다시 하게 된다 |

## 건드릴 파일

- 고칠 파일: `render.py`(요약 고르기) · `extract.py`(미분류 되돌리기 · 다시 안 부르기)
- 새로 만들 파일: `test_extract.py`
- 고칠 테스트: `test_render.py`

## 확인 방법

- `python -m unittest discover -p "test_*.py"` 통과
- `python render.py 2026-08-22` → `docs/2026-08-22.html` 의 영어 기사에 한국어 요약
- 배포 후 `curl -s https://semi-program.vercel.app | grep -c 'Nordson'` 으로 제목은 영어인지 확인
- 같은 날 `python extract.py` 를 두 번 → 두 번째는 모델 호출 0건

## 뚫는 순서 (`ROADMAP` 의 스켈레톤 연장 원칙)

1. **하루치**(2026-08-22, 이미 뽑아 둠)가 배포된 URL 에 뜨는 것까지 먼저
2. 그다음 최근 14일
3. 그다음 전체 125일 — 오래 걸리므로 뒤로 돌린다
