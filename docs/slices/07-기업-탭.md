# 기능: 사용자가 반도체 회사를 분류별로 보고, 회사별 기사만 모아 볼 수 있다

`ROADMAP.md` 2번(개념 사전)과 함께 나온 요청. **개념 사전 채우기는 이 슬라이스가 아니다.**

## 브레인스토밍에서 정해진 것

| 물음 | 답 |
| --- | --- |
| 탭의 역할 | 분류별 목록 **+ 회사별 기사 페이지 + 회사마다 설명** |
| 분류 개수 | **8개** (아래) |
| 한 회사가 여러 분류에 걸치면 | **여러 분류 허용.** 삼성전자는 메모리·파운드리 양쪽에 나온다 |
| 설명 출처 | **개념 사전과 같은 규칙** — 공식 사이트에서 옮기고 출처·확인일 기록 |
| 시작 규모 | **분류마다 5곳, 약 40곳** |
| 회사 페이지의 기사 범위 | **거른 것(반도체 관련) 기준.** 전체 수집분은 채용·가전이 섞이고, 하루 10건 선별분은 너무 좁다 |

## 분류 8개

`메모리` `팹리스` `파운드리` `종합(IDM)` `OSAT·후공정` `장비` `소재·부품` `EDA·IP`

**뉴스 카테고리(`keywords.md`)와 다른 체계다.** 뉴스는 *"무엇에 관한 기사인가"*,
기업은 *"밸류체인 어디에 있는 회사인가"* 다. 팹리스·OSAT 는 뉴스 카테고리에 없다.
개념 사전이 뉴스 카테고리를 그대로 쓰는 것과 달라지는데, **의도한 것이다.**

## 완료 조건

- [ ] 배포된 URL 상단에 `기업` 탭이 있고, 누르면 **분류별로 회사가 늘어선 목록**이 보인다
- [ ] 회사를 누르면 그 회사 페이지로 가고, **그 회사가 나온 기사만** 최신순으로 보인다
- [ ] 회사 페이지에 분류·설명·**출처 링크와 확인일**이 보인다

## 안 되는 경우

- 설명 출처가 아직 없는 회사 → **이름·분류는 보여주고 설명만 비운다.**
  개념 사전은 출처 없으면 항목 자체를 뺐지만, 여기서는 **목록 자체가 값**이라 다르게 간다
- 기사가 한 건도 없는 회사(ASML 등) → "아직 이 회사가 나온 기사가 없습니다"
- 기사가 아주 많은 회사 → 최신순 **최대 50건**까지만

## 이번에 안 하는 것

- **개념 사전 채우기** — 별도 작업. 이번엔 기업만
- **기업명 정규화 자동화** — `companies.md` 사전에 있는 것만 (`WBS.md` 3절, 계속 범위 밖)
- **미확인 회사 자동 수집** — 사전에 없는 이름을 쌓는 코드는 안 만든다
- **회사 간 관계도 그래프** — `PRD.md` 가 "데이터 3개월 뒤 재판단" 으로 미뤄 둔 것
- 흐름·요약·모델 — 아무것도 안 건드린다. 모델을 부르지 않는다

## 데이터 — `data/companies.md` 표를 넓힌다

```
| 정식명 | 별칭 | 분류 | 영문 | 국가 | 설명 | 출처 | 확인일 |
```

- **파일을 새로 만들지 않고 기존 표를 넓힌다.** 두 곳에 적으면 어긋난다 (세션 2 교훈)
- `분류` 는 쉼표로 여러 개: `메모리, 파운드리`
- **기존 파서는 안전하다** — `filter.py:67-70` 과 `link.py:37-41` 이 `cells[0]`·`cells[1]` 만 쓰고
  `len(cells) < 2` 로 방어한다. 열을 **뒤에** 붙이면 안 깨진다. 확인함

## 건드릴 파일

- 새로 만들 파일: `companies.py` (읽기 + 카드 HTML, `glossary.py` 와 같은 모양) · `test_companies.py`
- 고칠 파일: `data/companies.md`(열 추가·회사 채우기) · `render.py`(탭 · 목록 · 회사 페이지)

`render.py` 는 이미 359줄로 가장 크다. **읽기와 카드 HTML 은 `companies.py` 에 두고**
`render.py` 에는 페이지 껍데기 조립만 남긴다.

## 확인 방법

- `python -m unittest discover -p "test_*.py"` 통과 — **기존 50개가 그대로 통과해야 한다**
  (`companies.md` 를 넓혀도 `filter.py`·`link.py` 가 안 깨졌다는 뜻)
- `python render.py --all` → `docs/companies.html` 과 `docs/company/*.html` 생성
- 배포 후 `curl -s https://semi-program.vercel.app/companies.html | grep -c 'OSAT'` 이 0 보다 큼
- 배포 후 삼성전자 페이지가 200 이고 기사가 여러 건 보인다

## 뚫는 순서 (`ROADMAP` 의 스켈레톤 연장 원칙)

**40곳을 한 번에 채우지 않는다.** 설명마다 공식 사이트를 열어야 해서 회사당 요청 1번씩 든다.

1. 표에 열을 넣고 **3곳만** 채워서 `기업 탭 → 회사 페이지 → 기사 목록` 을 **배포까지 뚫는다**
2. 그다음 나머지를 분류별로 채운다
3. 중간에 끊겨도 1단계가 배포돼 있으므로 화면은 멀쩡하다
