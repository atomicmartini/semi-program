# 기능: 이어지는 흐름을 **키워드 겹침이 아니라 기사 내용**으로 판정한다

`06-연결고리-기준.md` 를 대체한다. 그 슬라이스가 세운 기준(기업 겹침 AND 키워드 겹침)이
실제 데이터에서 무너지는 것을 확인했다. 여기 적는 것이 새 기준이다.

## 지금 무엇이 문제인가

사용자가 2026-08-20 「SK하이닉스, CPO 청사진 공개」의 흐름 8건을 보고
**"CPO 와 긴밀히 연결된 건 하나도 없다"** 고 지적했다. 근거를 뽑아 보니 그대로였다.

| 붙은 과거 기사 | 겹친 기업 | 겹친 키워드 |
| --- | --- | --- |
| Intel — Investor Conferences 참가 | 인텔 | `ban` |
| SK하이닉스 HBM4E 샘플 공급 | SK하이닉스 | `메모리` |
| SK하이닉스 순현금 100조 | SK하이닉스 | `메모리`, `인공지능` |
| 최태원 회장 빅테크 회동 | SK하이닉스 | `ban`, `메모리`, `인공지능` |
| '슈퍼 모멘텀' 출간 | SK하이닉스 | `메모리` |
| 용인 클린룸 | SK하이닉스 | `메모리` |
| DDR4 가격 추월 | SK하이닉스 | `메모리` |
| DDR5 모듈 인텔 호환인증 | SK하이닉스, 인텔 | `메모리` |

**CPO 로 이어진 것은 8건 중 0건.** 원인은 둘이다.

1. **결정적인 말은 안 겹치고 흔한 말만 겹친다.** 이 기사가 가진 키워드는
   `cpo` `co-packaged optics` `메모리` `인공지능` `ban` 인데, CPO 를 특정하는 앞의 둘은
   과거 어느 기사와도 안 겹쳤다. 겹친 건 전부 흔한 쪽이다 — 거른 기사 303건 기준
   `메모리` 10% · `SK하이닉스` 9% · 둘 다 5%. **15건에 1건꼴로 그냥 걸리는 조합은 증거가 못 된다.**
   `06` 은 흔한 *기업*(삼성전자)만 경계하고 흔한 *키워드* 에는 같은 논리를 안 썼다.
2. **`ban` 이 `deutsche bank` 안에서 잡혔다.** 영문 키워드에 낱말 경계가 없다.
   `intel` ⊂ `intelligent`(companies.py), `ASIC` ⊂ `basic`(glossary.py) 에 이어 **세 번째**다.

여기에 더해, 정말 이어질 만한 기사는 **후보에 들어올 방법조차 없었다.**
2026-05-05 「GlobalFoundries Accelerates Adoption of Co-Packaged Optics」 는
`companies.md` 에 GlobalFoundries 가 없어 기업 겹침 조건에서 먼저 탈락한다.

## 먼저 재본 것 — 실패한 방법 네 가지

설계를 정하기 전에 버리는 probe 로 실측했다. **다 적어 둔다. 안 그러면 다음에 또 시도한다.**

| 방식 | 결과 |
| --- | --- |
| 본문 전체 임베딩 | **실패.** 위 약한 연결이 1~3위. 문체·회사명이 주제를 덮는다 |
| 주제 지문 전체 임베딩 | 개선되나 1위가 여전히 「최태원 회동」 |
| 지문을 항목 단위로 비교 (영어권 임베딩) | **악화.** `광 인터커넥트` ↔ `Co-packaged optics` 를 못 알아봐 진짜 CPO 기사가 꼴찌 |
| 지문 항목 단위 (다국어 임베딩) | 한·영은 붙지만 점수가 0.60~0.75 에 몰려 구분력이 없다. `광 인터커넥트` ↔ `화재사이드 채팅` 0.668 |

**공통 원인 — 흔한 개념은 실제로 많은 것과 의미가 가깝다.**
`차세대 메모리 연동`·`AI 인프라 구현` 같은 항목이 `메모리` 키워드가 하던 짓을 그대로 한다.
**유사도를 아무리 잘 재도 안 걸러진다.** 유사도 지표를 판정에 쓰는 길은 여기서 닫혔다.

## 새 기준

```
후보 = TF-IDF 상위 15건        (코드 · 놓치지 않는 일만 한다)
이어짐 = 모델이 그 후보를 읽고 고른 것 AND 근거 인용구가 원문에 실제로 있다
```

**후보 추리기와 판정을 분리한 것이 핵심이다.** 임베딩·TF-IDF 는 *놓치지 않기* 는 잘하고
*가려내기* 는 못한다(위 표). 그래서 좁히는 일만 시키고, 가려내는 일은 모델이 한다.

| 갈래 | 무엇 | 왜 |
| --- | --- | --- |
| 후보 | 오늘 기사와 과거 전체를 TF-IDF 코사인으로 재 상위 15건 | 돈이 안 든다. 실측 — GlobalFoundries 5위, Molex 14위로 상위 15건 안에 든다 |
| 판정 | 후보 15건 + 오늘 기사를 모델에 **한 번** 넘긴다 | 유사도 지표로는 못 가른다는 것을 네 번 확인했다 |
| 검사 | 인용구가 과거 기사 원문에 있는지 **코드가 대조** | 지어낸 연결을 막는 방어선. `extract.py._verify_quote` 를 그대로 쓴다 |

**기업 겹침·키워드 겹침 조건은 폐기한다.** 그게 GlobalFoundries 를 막고 있었다.
`relations`(기업 다리)도 연결 판정에서 뺀다 — `extract.py` 는 계속 뽑아 저장한다.

### 정하고 가는 값

| 무엇 | 값 | 왜 |
| --- | --- | --- |
| 후보 수 | 15건 | 실측에서 진짜 CPO 기사가 5위·14위였다. 너무 늘리면 프롬프트가 길어진다 |
| 후보를 재는 글 | 제목 + 요약 | 원문 전체는 저장하지 않는다 (`CLAUDE.md`) |
| 비교 대상 | 그날보다 **이전** 날짜의, 거르기를 통과한 기사 전체 | 지금 `link.py` 와 같다. 과거 범위 제한 없음 |
| 프롬프트에 넣는 요약 | 앞 300자 | 15건 × 요약이면 4~6K 토큰이라 무료 모델 한도에 닿을 수 있다 |
| 한 기사당 흐름 상한 | 10건 | 사용자가 정한 값, 그대로 |

한도에 걸리면 **후보를 10건으로 줄인다.** 요약을 더 자르지는 않는다 — 판정 근거가 얇아진다.

### 알고 가는 구멍

TF-IDF 는 **글자가 하나도 안 겹치면 못 찾는다.**
2026-04-29 「Kopin — MicroLED-Based Optical Interconnect」 는 한국어 기사가
`광 인터커넥트` 라고만 쓰고 영어 기사는 `Optical Interconnect` 라고만 써서 **50위로 탈락**한다.
임베딩이면 6위로 들어온다. 이 한 건이 유료 임베딩의 값어치다.

**돈 문제라서 무료를 골랐다.** 판정 모델은 `:free` 라 $0 이고, OpenRouter 에는 무료 임베딩이
없다. 실사용액은 연 몇 센트지만 **최소 선충전 $5~10 이 문턱**이다(계정 크레딧 $0 확인).
`shortlist()` 함수 하나만 갈아끼우면 임베딩으로 바꿀 수 있게 격리해 둔다.

## 저장 형식

`data/articles/<날짜>.linked.json` 의 `related[]`

```
지금:  date, title, url, shared_companies, shared_keywords
바꿈:  date, title, url, reason, quote
```

`shared_*` 는 지운다 — 화면에 쓰인 적이 없고 이제 판정 근거도 아니다.
모델이 실패하면 그 기사는 흐름 없음으로 두고 `link_error` 에 원문을 남긴다.

저장만 하고 안 보여주던 근거를 드러내는 것이 이번 변경의 값어치다.

## 안 되는 경우

- 모델이 하나도 안 고름 → **'이어지는 흐름 없음'.** 억지로 잇지 않는다 (`PRD.md`)
- 모델 호출 실패·JSON 깨짐 → 흐름 없음 + `link_error`. **조용히 넘기지 않는다**
- 인용구가 원문에 없음 → 그 연결만 버린다. 나머지는 남긴다
- 글자가 안 겹치는 한↔영 기사 → 못 잇는다 (위 '알고 가는 구멍')

## 이번에 안 하는 것

- **임베딩 안 쓴다** — 돈 문제. 자리만 만들어 둔다
- **`extract.py` 안 건드린다** — `relations` 는 계속 저장한다
- **`keywords.md` 의 `ban` 은 이번에 안 고친다** — 연결에서 키워드를 아예 안 쓰게 되어 이 경로로는 못 샌다.
  `filter.py` 의 낱말 경계 문제는 따로 남는다
- **상한 10건 그대로** — 사용자가 정한 값

## 규칙 개정 (`CLAUDE.md`)

지금 규칙은 **"점수 매기기·판정은 코드가 한다. 모델은 분류·요약·관계 추출만 한다"** 이다.
연결 판정을 모델에게 주므로 이 문장과 정면으로 부딪힌다. **사용자 승인 아래 이렇게 고친다.**

> 연결 판정은 모델이 한다. 다만 **근거 인용구가 원문에 실제로 있는지는 코드가 대조해 검사하고,
> 통과 못 한 연결은 버린다.** 점수 매기기·기업명 정규화는 여전히 코드가 한다.

지어낸 연결을 막는 실제 방어선은 그대로 코드에 남는다.

## 만들고 나서 알게 된 것 (2026-09-04)

명세를 쓸 때 몰랐던 것들이다. **다음에 같은 함정을 파지 않으려고 적는다.**

| 무엇 | 어떻게 됐나 |
| --- | --- |
| **무료 모델 하루 50건 상한** | 재판정에 약 224건이 필요한데 하루 50건이라 **여러 날에 나눠 돌린다**. 그래서 `backfill.py` 를 만들었다 |
| **429 에는 이유가 안 담긴다** | `urlopen` 이 응답 본문을 안 읽고 예외를 던져서 기록에 남는 건 `HTTP Error 429: Too Many Requests` 뿐이다. 제공자가 보낸 `Rate limit exceeded: free-models-per-day` 를 찾는 코드는 **영원히 못 찾는다.** 첫 `backfill.py` 가 이 버그로 할당량에 걸려도 안 멈출 뻔했다 — **429 면 무조건 멈춘다** 로 고쳤다 |
| **`.linked.json` 은 복구가 안 된다** | gitignore 라 덮어쓰면 끝이다. 그래서 `link_day` 는 이미 판정된 기사를 다시 부르지 않고(`load_done`), 실패 하나 때문에 그날 전체를 날리지 않는다 |
| **옛 파일과 '연결 없음' 이 구분이 안 됐다** | 옛 규칙도 '링크 0건·오류 0건' 을 만들어서, 재판정이 필요한 날을 못 골랐다. 저장할 때 `judged` 표식을 남겨 구분한다 |
| **모델은 영어 기사엔 영어로 답한다** | `reason` 이 영어로 나왔다. 화면이 한국어라 프롬프트에 "reason 은 항상 한국어, quote 는 원문 그대로" 를 박았다 |
| **인용구 없는 옛 링크가 계속 게시됐다** | `render_thread` 가 근거 줄만 감추고 링크는 그대로 실었다. 백필이 끝날 때까지 잡음이 남는다는 뜻이라, **인용구 없는 연결은 아예 안 싣게** 고쳤다 |
| **인용구 길이 하한** | `_verify_quote` 는 부분 문자열이면 통과라 `CPO` 세 글자로도 뚫린다. 지금 이게 유일한 날조 방어선이라 **10자 하한**을 뒀다 |

**실제 결과** — 8/20 CPO 기사의 흐름이 8건 → 2건(Molex·GlobalFoundries)으로 줄었고,
남은 2건은 인용구가 원문 대조를 통과했다. 지적받은 잡음 링크는 전부 사라졌다.
