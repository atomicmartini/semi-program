# 기능: 사용자가 흐름에서 **정말 이어지는** 기사만 볼 수 있다

`ROADMAP.md` 3번. 모델을 부르지 않는다 — 오늘 일일 한도(50건)를 다 써서 그 편이 낫기도 하다.

## 지금 무엇이 문제인가

**공통 기업 1개만 겹치면 잇는다.** 그래서 이런 게 이어져 있다.

> **주주환원 90조원 의결** ←→ **IDEA·레드닷 디자인 어워드 수상**
> (겹치는 것: `삼성전자` 하나뿐)

`PRD.md` 가 노리는 *"이게 전에 그 얘기랑 이어지나"* 와 정반대다.
삼성전자는 거의 모든 한국어 기사에 나오므로 **증거가 되지 못한다.**

## 새 기준

```
이어짐 = (기업이 직접 겹침  OR  관계로 이어진 기업)  AND  키워드가 겹침
```

**둘 다** 만족해야 잇는다.

| 갈래 | 무엇 | 어디서 오나 |
| --- | --- | --- |
| 기업 — 직접 | 두 기사에 같은 회사가 나온다 | `data/companies.md` |
| 기업 — **다리** | 회사가 달라도 **관계로 이어져 있다** | `extract.py` 가 뽑은 `relations` |
| 키워드 | 무엇에 관한 기사인지가 겹친다 | `data/keywords.md` 의 **카테고리 키워드** |

**다리**가 사용자가 말한 그것이다 — *"NVIDIA 가 뭘 개발했는데 그걸 삼성이 만들기로 했다"*.
`relations` 에 `[NVIDIA, 삼성전자]` 가 있으면, NVIDIA 기사와 삼성 기사를 잇는다.
지금 다리는 **9건**뿐이다 (`Qnity↔KLA`, `한미반도체↔Mercury` 등). 모델을 더 돌리면 늘어난다.

**키워드는 카테고리 키워드만 쓴다.** `포함` 목록(`반도체` 등)은 거의 모든 기사에 걸려서
증거가 못 된다 — 흔한 기업명과 같은 이유다.

## 완료 조건

- [ ] 주주환원 기사와 디자인 어워드 기사가 **더 이상 안 이어진다**
- [ ] 기업이 달라도 `relations` 에 있는 짝이면 이어진다
- [ ] 키워드가 하나도 안 겹치면, 기업이 겹쳐도 안 이어진다

## 안 되는 경우

- `relations` 가 아직 없음(`extracted.json` 없는 날) → 다리 없이 직접 겹침만으로 판정. 에러 아님
- 새 기준으로 아무것도 안 이어짐 → **'이어지는 흐름 없음'.** 억지로 잇지 않는다 (`PRD.md`)
- 기업명이 `companies.md` 에 없음 → 지금처럼 못 찾는다. 이번에 사전을 늘리지 않는다

## 이번에 안 하는 것

- **기업명 정규화 시스템은 안 만든다** — `companies.md` 사전에 있는 것만 (`WBS.md` 3절, 범위 밖)
- **흔한 기업 가중치 점수식은 안 만든다** — 키워드 조건이 같은 일을 더 단순하게 한다
- **상한 10건은 그대로** — 사용자가 정한 값
- 모델을 부르지 않는다. `extract.py` 는 안 건드린다
- 화면(`render.py`)은 안 건드린다 — 데이터만 바뀐다

## 건드릴 파일

- 고칠 파일: `link.py`
- 고칠 테스트: `test_link.py`

## 확인 방법

- `python -m unittest discover -p "test_*.py"` 통과
- `python link.py 2026-08-22` → 주주환원 기사의 흐름에 **디자인 어워드가 없다**
- `python render.py --all` 후 배포 → 흐름 블록이 남아 있고 내용이 더 좁아졌다

## 물어볼 것

- 키워드가 **몇 개** 겹쳐야 하나. 우선 **1개**로 두고 실제 데이터로 확인한 뒤,
  너무 헐거우면 2개로 올린다. 결과를 보고 사용자에게 알린다
