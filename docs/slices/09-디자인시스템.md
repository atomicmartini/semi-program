# 09 — 디자인 시스템

> 계기: Dribbble `JRNL - Newsletter Mobile Apps` (Kretya) 참고. 사진·아바타는 없어서
> 그대로 베끼지 않고, **색은 흰 배경 위 단일 포인트 컬러**·**카드는 테두리 대신 은은한
> 그림자+둥근 모서리**라는 방향만 가져왔다.

## 정한 것

| 무엇 | 정한 값 | 왜 |
| --- | --- | --- |
| 포인트 컬러 | 기존 남색(`#0b2e6b`) 유지 | 이미 Axios 스타일로 배포돼 있고 사용자가 유지를 선택함 |
| 카드 모양 | 테두리 제거, `box-shadow` + 모서리 8px→14px | Dribbble 참고작의 카드가 이 모양. hover 시 그림자가 진해지고 1px 뜬다 |
| 탭·칩 | 그대로 (알약 모양, 그림자 없음) | 참고작도 탭엔 그림자를 안 쓴다. 이미 방향이 같았다 |

## 토큰 (`render.py` `STYLE`의 `:root`)

```
--page #fbfbfa   페이지 배경
--surface #fff   카드·항목 배경
--text #1c1b19 / --text-muted #63605a / --text-faint #94908a   글자 3단계
--border #e4e2dd / --border-soft #f0eeea   구분선
--accent #0b2e6b   상단바·선택된 탭·칩
--link #0b5fff   하이퍼링크·포커스
--success #0a7d3c   '확정' 배지
--radius-sm 8px (칩·작은 요소) / --radius-lg 14px (카드)
--shadow-card / --shadow-hover   카드 기본/hover 그림자
```

**주의 — `--bg`/`--fg`는 건드리지 않았다.** `category_chips()`가 카테고리마다
인라인으로 넣는 전용 변수라(render.py:304), 페이지 배경 토큰을 `--bg`로 지었으면
이름이 겹쳐 칩 색이 깨졌을 것이다. 그래서 페이지 배경은 `--page`로 이름을 다르게 뒀다.

## 바뀐 컴포넌트

`.card` `.entry` `.profile` `.colist-articles` `a.co` — `border:1px solid` 제거,
`box-shadow:var(--shadow-card)` + `border-radius:var(--radius-lg)`(또는 `a.co`는 `--radius-sm`)로 교체.
클릭 가능한 카드(`.card` `a.co`)는 hover 시 `--shadow-hover` + `translateY(-1px)`.

색상은 전부 헥스 값 대신 토큰으로 치환했다 (`#0b2e6b` → `var(--accent)` 등). 값 자체는 안 바꿨다.

## 모바일

- `.wrap` 좌우 여백 24px → 14px (600px 이하)
- `.card`/`.entry`/`.profile` 내부 padding 16~20px → 14px
- 카드·항목 제목에 `overflow-wrap:break-word` — 영문 기사 제목이 길 때 화면 밖으로 안 넘치게
- `.carow`(기업 페이지 기사 목록)에 `flex-wrap` 추가 — 날짜+제목이 좁은 화면에서 줄바꿈되게
- `.rail`(이어지는 흐름) 좁은 화면 레이아웃은 기존 규칙 그대로 유지

## 손 안 댄 것

- HTML 구조(클래스명)는 안 바꿨다 — `test_render.py`가 안 깨진다
- 카테고리 칩 파스텔 색·이모지는 그대로
- 폰트 크기 스케일은 그대로 (필요성이 확인 안 됨)
