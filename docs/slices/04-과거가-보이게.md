# 기능: 사용자가 배포된 URL 에서 예전 기사를 볼 수 있다

슬라이스 03 으로 데이터는 125일(`2025-11-03~`)이 됐는데 **화면에는 아무 변화가 없었다.**
`render.py` 가 최근 **14일**만 HTML 로 만들기 때문이다 (`render.py:200,279`).
그래서 2025-11~2026-04 은 **페이지 자체가 없다.**

## 이번 범위 — 오직 '예전 기사가 URL 에 보이는 것'

연결고리(무엇을 무엇에 잇는가)는 **이번에 손대지 않는다.**
지금 기준(공통 기업 1개)이 헐겁다는 것은 알고 있고, **더 빡세게 하는 것은 다음 작업**이다.

바꾸는 것은 둘뿐이다.

| 무엇 | 지금 | 바꿀 것 |
| --- | --- | --- |
| `render.py` 날짜 범위 | 최근 14일 | **기사가 있는 날 전부** |
| `link.py` `MAX_RELATED` | 3 | **10** |

## 완료 조건

- [ ] `python render.py --all` 이 기사가 있는 **모든 날짜**의 HTML 을 만든다 (지금 125개)
- [ ] 배포된 URL 하단 날짜 줄에서 **2025년 날짜로 갈 수 있다**
- [ ] `docs/2025-11-10.html` 같은 과거 페이지가 열리고 그날 기사가 보인다

## 안 되는 경우

- 기사가 0건인 날 → 지금처럼 '이 날은 기사가 없습니다'. 그대로 둔다
- 날짜가 125개라 줄이 길어짐 → **달별로 묶어서** 보여준다. 한 줄에 다 늘어놓지 않는다
- 과거 날짜에 `linked.json` 이 없음 → 흐름 블록이 없을 뿐, 에러 아님

## 이번에 안 하는 것

- **연결고리 기준(공통 기업 1개)은 안 바꾼다** — 사용자가 다음에 직접 정하기로 했다
- **고르는 규칙(A/B/C)도 안 만든다** — 상한만 10 으로 올린다. 후보가 20건이면 10건 안에 과거가 섞여 들어온다
- `extract.py` 는 안 건드린다 (모델 429, 여전히 막힘)
- 배지(`확정`/`보도됨`)·'달라진 점' 문구 — 근거가 없다
- 과거 날짜 전부에 `link.py` 를 돌리지 않는다 — 최근 14일만. 나머지는 흐름 없이 목록만 보인다

## 건드릴 파일

- 고칠 파일: `render.py`(날짜 범위·날짜 줄) · `link.py`(`MAX_RELATED` 상수)
- 고칠 테스트: `test_render.py`

## 확인 방법

- `python -m unittest discover -p "test_*.py"` 통과
- `python render.py --all` → `docs/` 에 125개 날짜 HTML
- 배포 후 `curl -s https://semi-program.vercel.app | grep -c '2025-11'` 이 0 보다 큼
- `curl -s -o /dev/null -w "%{http_code}" https://semi-program.vercel.app/2025-11-10.html` 이 200

## 물어볼 것

없음. 범위와 상한은 위에서 정해졌다.
