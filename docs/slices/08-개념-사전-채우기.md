`ROADMAP.md` 2번(개념 사전). 세션 8에서 회사 설명 26곳을 채운 것과 같은 방식으로,
이번에는 **용어**를 채운다.

## 브레인스토밍에서 정해진 것

| 물음 | 답 |
| --- | --- |
| 무엇부터 | **용어 채우기부터.** 미등재 자동 수집은 이번이 아니다 |
| 출처 범위 | **공식만 고집하지 않는다.** 흔하게 통용되는 설명이면 다른 곳도 쓴다 |

| 첨단 패키징 | **뺀다.** 너무 포괄적인 말이라 개념으로 세우면 아무거나 다 걸린다 |
| 리소그래피 · 팹리스 | **뺀다** |

## 넣을 용어 13개

기사 214건에서 센 등장 횟수를 괄호에 적는다.

| 계열 | 용어 |
| --- | --- |
| HBM 계보 | HBM(10) · HBM2(0) · HBM2E(0) · HBM3(0) · HBM3E(0) · HBM4(3) |
| 패키징 | 칩렛(8) · 하이브리드 본딩(6) · SiP(1) |

분류는 `data/glossary.md` 아래에 이미 있는 7개 안에서만 쓴다. **임의로 늘리지 않는다** (`CLAUDE.md`).

## 먼저 고칠 것 — `glossary.py` 에 낱말 경계가 없다

`companies.py` 가 이미 고친 그 버그가 `glossary.py` 에는 남아 있다.

```
link_terms("This is a basic association test", [ASIC, SoC])
  → "a b[asic] as[soc]iation test"
```

지금 등재어가 한글 위주라 안 터졌을 뿐이다. **ASIC·SoC·SiP·NPU 를 넣는 순간 화면에 깨진 링크가 보인다.**
`companies.py:120 _alias_pattern` 과 같은 방식으로 고친다 — 영문만 낱말 경계를 요구하고,
한국어는 조사가 붙으므로(`패키징을`) 그냥 포함으로 본다.

## 안 되는 경우

- **HBM2 · HBM3 는 지금 기사에 0건** → 개념 탭에는 뜨지만 기사 본문 링크는 안 걸린다.
  세션 3은 이런 용어를 뺐지만, 이번엔 **계보의 중간이 비면 오히려 이상해 보인다**는 판단으로 넣는다.
  둘은 다른 상황이다 — 세션 3은 홀로 뜨는 용어였고, 여기는 이어진 계보의 일부다
- **출처를 못 읽은 용어** → 그 줄을 아예 넣지 않는다. `glossary.py` 가 출처·확인일 없는 줄을 이미 거른다.
  기업 탭과 다른 점이다 — 기업은 목록 자체가 값이라 설명만 비웠지만, 개념은 **설명이 곧 항목**이다
- 별칭이 다른 용어를 잡아먹는 경우 → 긴 것부터 찾는 기존 장치(`patterns` 정렬)가 처리한다.
  `HBM4` 가 `HBM` 보다 먼저 잡혀야 한다
